# Passify Mobs

A mob list, which contains the most common overworld hostile mobs by default, 
is generated as a config. This list can be edited post creation to contain
a different mob set.

When the configs are changed, or when the plugin is first added to the 
server, you must log into the server and run the command 
*/update_passifieds* in order to update the mobs that are passified.

The mobs are only passified to select players. This player list can be added
to or removed from with the command */passive_to*. The players on this
list can also be read with this command.
